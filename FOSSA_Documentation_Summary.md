# PRODUCTION NOTES FOR VIDEOGRAPHER

## Brand Guidelines
- **Primary Colour:** Use LeaseStash brand colours throughout
- **Font:** Match website typography
- **Logo:** Always include LeaseStash logo in intro and outro
- **Tone:** Clean, modern, professional — not overly salesy

## Technical Specs
| Spec | Requirement |
|------|-------------|
| Resolution | 1080p minimum (1920×1080) |
| Format | MP4 (H.264) |
| Frame Rate | 30fps |
| Audio | Clear voiceover or clean music + text overlays |
| Subtitles | Preferred for accessibility |
| Max Duration | 90 seconds per video |

## Screen Recording Tips
- Use a demo account — never show real user data
- Zoom into key buttons and form fields for clarity
- Use cursor highlight (yellow ring or spotlight effect)
- Smooth scroll — avoid jerky mouse movements

## Suggested Motion Graphics Elements
- Animated callout arrows pointing to buttons
- Text pop-ins for key terms (e.g., "Escrow", "Digital Signature")
- Progress bar or step tracker (Step 1 of 4, etc.)
- Subtle zoom-ins when clicking or submitting forms
- Checkmark animation when a step is completed

## Delivery
- Provide raw edit + final export per video
- Name files: `LeaseStash_V01_PlatformOverview.mp4`, `LeaseStash_V02_SignUp.mp4`, etc.
- Include project files (After Effects / Premiere / DaVinci) for future edits
